# TMUA / ESAT Maths Diagnostic

A free, self-contained 8-question maths diagnostic for TMUA / ESAT applicants:
a 30-minute timer, automatic scoring, a per-topic breakdown and full worked
solutions. Every answer is computed and verified in code.

**Live:** https://brockenl.github.io/tmua-esat-diagnostic/

Independent practice material by Oxbridge Maths Lab. Not affiliated with
UAT-UK, Pearson VUE, or any exam board. This is not an official past paper.
